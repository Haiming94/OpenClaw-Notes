# SearXNG + OpenClaw 搜索服务部署教程

## 概述

本教程指导你在一台宿主机上部署 SearXNG 搜索服务容器，并为同机 Docker 容器中的 OpenClaw 配置 SearXNG 作为搜索 provider。

**最终效果：** OpenClaw 可以使用 SearXNG 进行网页搜索，无需第三方 API Key。

---

## 前置条件

- 宿主机已安装 Docker
- 已有一个运行 OpenClaw 的 Docker 容器（本教程以 `my123` 为例）
- 宿主机 8080 端口未被占用

检查 8080 端口是否可用：

```bash
ss -tlnp | grep 8080
```

无输出表示端口可用。

---

## 第一步：部署 SearXNG 容器

### 1.1 创建配置目录

```bash
mkdir -p /mnt/disk6t2/project/searxng
```

### 1.2 创建 SearXNG 配置文件

创建文件 `/mnt/disk6t2/project/searxng/settings.yml`，内容如下：

```yaml
use_default_settings: true

search:
  safe_search: 0
  autocomplete: ""
  default_lang: "auto"
  formats:
    - html
    - json

server:
  secret_key: "searxng-secret-key-change-me"
  limiter: false
  image_proxy: false
  bind_address: "0.0.0.0"
  port: 8080

ui:
  static_use_hash: true

engines:
  - name: google
    engine: google
    shortcut: g
    disabled: false
  - name: bing
    engine: bing
    shortcut: b
    disabled: false
  - name: duckduckgo
    engine: duckduckgo
    shortcut: ddg
    disabled: false
  - name: wikipedia
    engine: wikipedia
    shortcut: wp
    disabled: false
```

> **说明：** `formats` 中必须包含 `json`，否则 OpenClaw 无法调用 SearXNG API。

### 1.3 拉取镜像并启动容器

```bash
# 拉取镜像
docker pull searxng/searxng:latest

# 如果存在同名旧容器，先删除
docker rm searxng 2>/dev/null

# 启动容器
docker run -d \
  --name searxng \
  --restart unless-stopped \
  -p 8080:8080 \
  -v /mnt/disk6t2/project/searxng/settings.yml:/etc/searxng/settings.yml:ro \
  searxng/searxng:latest
```

### 1.4 验证 SearXNG 是否正常

```bash
# 等待几秒让服务启动
sleep 5

# 测试 JSON API
curl -s "http://localhost:8080/search?q=test&format=json" | python3 -c "
import sys, json
d = json.load(sys.stdin)
print(f'返回 {len(d.get(\"results\", []))} 条结果')
"
```

预期输出：`返回 10 条结果`

## 第二步：配置 OpenClaw 使用 SearXNG

### 2.1 确认 OpenClaw 容器信息

```bash
# 查看运行中的容器
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"

# 确认容器网络（找到你的 OpenClaw 容器名）
docker inspect <你的容器名> --format '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}'
```

### 2.2 确认 OpenClaw 配置文件路径

```bash
# 进入容器查看 HOME 目录
docker exec <你的容器名> env | grep HOME
```

OpenClaw 配置文件位于 `$HOME/.openclaw/openclaw.json`。

> **注意：** 如果 HOME 是 `/home/kasm-user`，配置路径为 `/home/kasm-user/.openclaw/openclaw.json`。
> 如果 HOME 是 `/root`，配置路径为 `/root/.openclaw/openclaw.json`。
> 后续命令中用 `<配置路径>` 代替实际路径。

### 2.3 确认 SearXNG 从容器内可达

```bash
# 172.17.0.1 是 Docker bridge 网关，即宿主机 IP
docker exec <你的容器名> curl -s "http://172.17.0.1:8080/search?q=test&format=json" | python3 -c "
import sys, json
d = json.load(sys.stdin)
print(f'从容器内访问 SearXNG: {len(d.get(\"results\", []))} 条结果')
"
```

预期输出：`从容器内访问 SearXNG: 10 条结果`

> **如果访问失败：** 检查宿主机防火墙是否放行了 8080 端口，或尝试使用宿主机实际 IP（通过 `hostname -I` 查看）。

### 2.4 启用 SearXNG 插件

```bash
docker exec <你的容器名> bash -c '
  OPENCLAW_CONFIG_PATH=<配置路径> openclaw plugins enable searxng
'
```

预期输出：`Enabled plugin "searxng". Restart the gateway to apply.`

### 2.5 配置 SearXNG 地址

```bash
docker exec <你的容器名> bash -c '
  OPENCLAW_CONFIG_PATH=<配置路径> openclaw config set plugins.entries.searxng.config.webSearch.baseUrl "http://172.17.0.1:8080"
'
```

### 2.6 验证配置

```bash
docker exec <你的容器名> bash -c '
  OPENCLAW_CONFIG_PATH=<配置路径> openclaw config get plugins.entries.searxng
'
```

预期输出：

```json
{
  "enabled": true,
  "config": {
    "webSearch": {
      "baseUrl": "http://172.17.0.1:8080"
    }
  }
}
```

## 第三步：重启 OpenClaw 网关

配置修改后需要重启网关才能生效。

### 3.1 重启容器

```bash
docker restart <你的容器名>
```

### 3.2 启动 OpenClaw 网关

```bash
# 等待容器启动完成
sleep 10

# 在后台启动网关
docker exec -d <你的容器名> bash -c '
  OPENCLAW_CONFIG_PATH=<配置路径> openclaw gateway run --bind loopback > /tmp/openclaw-gateway.log 2>&1
'
```

### 3.3 验证网关运行

```bash
sleep 5
docker exec <你的容器名> curl -s http://127.0.0.1:18789/health
```

预期输出：`{"ok":true,"status":"live"}`

### 3.4 验证插件加载

```bash
docker exec <你的容器名> bash -c '
  OPENCLAW_CONFIG_PATH=<配置路径> openclaw plugins inspect searxng
'
```

预期输出中应包含：

```
Status: loaded
Capabilities:
  web-search: searxng
```

---

## 第四步：验证搜索功能

### 4.1 检查插件状态

```bash
docker exec <你的容器名> bash -c '
  OPENCLAW_CONFIG_PATH=<配置路径> openclaw plugins list
' | grep searxng
```

预期输出中 `Status` 列应为 `enabled`。

### 4.2 通过 OpenClaw 使用搜索

在 OpenClaw 对话中，agent 会自动使用已配置的搜索 provider。默认使用 tavily，SearXNG 作为备选。

如需将 SearXNG 设为默认搜索：

```bash
docker exec <你的容器名> bash -c '
  OPENCLAW_CONFIG_PATH=<配置路径> openclaw config set tools.web.search.provider searxng
'
```

如需改回 tavily：

```bash
docker exec <你的容器名> bash -c '
  OPENCLAW_CONFIG_PATH=<配置路径> openclaw config set tools.web.search.provider tavily
'
```

## 常见问题

### Q: SearXNG 容器启动后无法访问

检查容器日志：

```bash
docker logs searxng --tail 50
```

常见原因：settings.yml 格式错误（YAML 缩进问题）。

### Q: 从 OpenClaw 容器内访问 SearXNG 失败

确认网络连通性：

```bash
# 在 OpenClaw 容器内 ping 宿主机
docker exec <你的容器名> ping -c 2 172.17.0.1
```

如果 ping 不通，尝试使用宿主机实际 IP：

```bash
# 在宿主机上查看 IP
hostname -I
```

然后将配置中的 `172.17.0.1` 替换为实际 IP。

### Q: 重启容器后 OpenClaw 网关没有自动启动

OpenClaw 网关在容器内以进程方式运行，容器重启后需要手动启动（见第三步 3.2）。

如需开机自动启动，可以在宿主机上添加 crontab：

```bash
crontab -e
```

添加一行（替换容器名和配置路径）：

```
@reboot sleep 30 && docker exec -d <你的容器名> bash -c 'OPENCLAW_CONFIG_PATH=<配置路径> openclaw gateway run --bind loopback > /tmp/openclaw-gateway.log 2>&1'
```

### Q: 如何更新 SearXNG

```bash
docker pull searxng/searxng:latest
docker stop searxng
docker rm searxng
# 重新执行第一步的 docker run 命令
```

## 网络架构说明

```
宿主机 (172.17.0.1)
├── SearXNG 容器 (:8080)
└── my123 容器 (172.17.0.8)
    └── OpenClaw 网关 (:18789)
        └── 访问 SearXNG → http://172.17.0.1:8080
```

- Docker bridge 网关 `172.17.0.1` 代表宿主机
- OpenClaw 容器通过此 IP 访问宿主机上运行的 SearXNG
- SearXNG 监听 `0.0.0.0:8080`，接受来自任何网络的请求
